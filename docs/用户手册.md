# ComfyUI WebApp 用户手册

## 1. 产品简介

ComfyUI WebApp 用于把现有 ComfyUI 工作流封装成可重复运行的 Web 应用，并提供任务监控页面来管理执行结果。

当前版本支持：

- 从工作流 JSON 创建 WebApp
- 自动提取可编辑节点字段
- 编辑应用名称、描述、标签和节点配置
- 发布 WebApp 后在前端填写参数并执行
- 查看任务状态、错误信息、输出文件
- 批量删除任务、批量下载任务输出
- 通过用户 ID 实现多用户数据隔离

## 2. 访问入口

### 2.1 WebApp 管理页

浏览器访问：

```text
http://localhost:8188/webapp/index.html
```

### 2.2 任务监控页

浏览器访问：

```text
http://localhost:8188/webapp/tasks.html
```

### 2.3 用户切换

两个页面顶部都提供了用户 ID 输入框：

- 不填写时默认使用 `default`
- 修改输入框后会重新加载当前用户的应用或任务
- API 调用也可以通过 `X-User-ID` 或 `user_id` 参数指定用户

## 3. 快速开始

### 3.1 创建第一个 WebApp

1. 在 ComfyUI 中准备好工作流并导出 JSON
2. 打开 `http://localhost:8188/webapp/index.html`
3. 在页面右上角确认当前用户 ID
4. 点击“创建 WebApp”
5. 通过以下任一方式提供工作流：
   - 上传本地 `.json` 工作流文件
   - 直接粘贴工作流 JSON
6. 填写应用名称和描述
7. 点击创建

创建成功后，系统会自动：

- 解析工作流
- 提取可编辑字段
- 生成默认的节点配置
- 将 WebApp 保存到当前用户目录

### 3.2 编辑 WebApp

在应用卡片点击“编辑”后，可以修改：

- 应用名称
- 应用描述
- 标签
- 节点配置

节点配置页支持：

- 勾选或调整要暴露给用户的输入字段
- 修改 `displayName`
- 修改 `description`
- 编辑默认值 `fieldValue`
- 保存 `nodeInfoList`

常见字段类型：

| 类型 | 用途 |
|------|------|
| IMAGE | 上传或选择输入图片 |
| STRING | 文本参数 |
| INT | 整数参数 |
| FLOAT | 小数参数 |
| BOOLEAN | 开关参数 |
| LIST | 枚举或下拉类参数 |

### 3.3 发布 WebApp

发布步骤：

1. 确认工作流和节点配置已保存
2. 在应用卡片点击“发布”
3. 发布成功后状态变为 `published`
4. 已发布应用会显示“运行”按钮

## 4. 运行应用

### 4.1 打开运行弹窗

1. 在已发布应用卡片点击“运行”
2. 系统会根据 `nodeInfoList` 生成表单

### 4.2 填写参数

不同字段类型对应不同输入方式：

- **IMAGE**：上传新文件，或从当前用户 input 目录中已有文件中选择
- **STRING / INT / FLOAT / BOOLEAN**：直接输入或切换
- **LIST**：选择预设选项

### 4.3 提交任务

1. 确认参数无误
2. 点击弹窗中的执行按钮
3. 提交成功后会跳转到任务监控页，并带上新任务的高亮定位参数

## 5. WebApp 管理页说明

### 5.1 页面功能

首页支持以下操作：

- 查看当前用户的全部 WebApp
- 按状态筛选 `draft` / `published`
- 创建 WebApp
- 编辑 WebApp
- 发布 WebApp
- 删除 WebApp
- 打开运行弹窗

### 5.2 应用卡片信息

应用卡片当前显示的核心信息包括：

- 应用名称
- 应用 ID
- 描述
- 节点字段数量
- 标签
- 状态
- 更新时间

### 5.3 删除应用的实际行为

删除 WebApp 时，当前版本会：

- 删除 WebApp 配置文件
- 从内存索引中移除该 WebApp

当前版本不会自动：

- 删除该 WebApp 的历史任务记录
- 删除该 WebApp 已生成的任务输出目录

## 6. 任务监控页说明

### 6.1 页面结构

任务页包含：

- 用户 ID 输入框
- 状态统计卡片
- 状态筛选
- 应用筛选
- 关键字搜索
- 管理模式工具栏
- 任务卡片列表

### 6.2 任务状态

| 状态 | 说明 | 可用操作 |
|------|------|----------|
| pending | 等待执行 | 取消 |
| running | 正在执行 | 取消 |
| completed | 已完成 | 下载全部、重新运行、删除 |
| failed | 执行失败 | 查看错误、重新运行、删除 |
| cancelled | 已取消 | 重新运行、删除 |

### 6.3 任务卡片信息

每个任务卡片会显示：

- 应用名称
- 任务 ID
- 当前状态
- 创建时间
- 执行耗时
- 重试次数
- 进度条
- 输出结果
- 运行参数
- 错误信息

### 6.4 常用操作

**查看参数**

- 点击“运行参数”标题可展开参数列表

**查看错误**

- 失败任务会显示“错误信息”区域
- 点击标题后可展开完整错误文本

**下载结果**

- 单个文件：在输出缩略图区域点击下载
- 整个任务：点击“下载全部”

**重新运行**

- 已完成、失败、已取消的任务都可以重新运行
- 系统会打开一个重新提交弹窗
- 可以沿用原参数，也可以先修改参数再提交
- 图片类参数会尝试从之前保存的 Base64 内容中恢复到输入目录

**取消任务**

- `pending` 和 `running` 状态都可以取消

**删除任务**

- 删除任务会同时删除任务 JSON 和该任务的输出目录

### 6.5 批量管理

点击“管理”后可进入批量模式，支持：

- 选择当前筛选结果中的任务
- 全选 / 取消全选
- 批量删除
- 批量下载

批量下载只对“已完成且存在输出文件”的任务有效。

## 7. 多用户数据隔离

### 7.1 用户识别方式

系统按以下顺序识别用户：

1. 请求头 `X-User-ID`
2. 查询参数 `user_id`
3. 默认值 `default`

### 7.2 存储位置

**默认用户 `default`**

- 应用配置：`user/webapp/`
- 任务数据：`user/tasks/`
- 输入文件：`input/`
- 输出文件：`output/`
- 临时文件：`temp/`

**非默认用户**

- 应用配置：`user/{user_id}/webapp/`
- 任务数据：`user/{user_id}/tasks/`
- 输入文件：`user/{user_id}/input/`
- 输出文件：`user/{user_id}/output/`
- 临时文件：`user/{user_id}/temp/`

### 7.3 隔离效果

- 用户 A 的上传文件不会出现在用户 B 的目录中
- 用户 A 的 WebApp 列表不会与用户 B 混合
- 用户 A 的任务记录和输出结果只会写入用户 A 的目录

## 8. 当前版本注意事项

以下行为与旧文档描述不同，使用时请以当前版本为准：

- 前端页面已经支持直接输入用户 ID 进行切换
- 当前没有“取消发布”按钮，也没有对应前端入口
- 当前前端没有封面图片编辑入口
- 创建弹窗虽然展示运行模式选项，但创建接口当前只持久化 `name`、`description`、`workflow`
- 删除 WebApp 不会自动级联清理历史任务

## 9. 常见问题

### 9.1 创建时提示工作流无效

请检查：

- 上传或粘贴的内容是否是完整 JSON
- 工作流对象是否包含有效节点结构
- 是否误传了空对象

### 9.2 看不到可编辑输入字段

请检查：

- 工作流中是否存在可编辑输入节点
- 节点字段是否能被当前节点映射逻辑识别
- 创建后可先在编辑页查看并调整节点配置

### 9.3 任务一直停留在待处理

请检查：

- 当前 ComfyUI 是否正在执行其他任务
- 机器资源是否充足
- 刷新任务页确认状态是否更新

### 9.4 任务失败后如何查看原因

在任务页找到失败任务，展开“错误信息”即可查看后端返回的错误文本。

### 9.5 如何备份数据

建议至少备份以下目录：

- 默认用户应用：`user/webapp/`
- 默认用户任务：`user/tasks/`
- 普通用户应用：`user/{user_id}/webapp/`
- 普通用户任务：`user/{user_id}/tasks/`

如果还需要保留上传文件和输出结果，也应同时备份对应的 `input/`、`output/` 目录。
